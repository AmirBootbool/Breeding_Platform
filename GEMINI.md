# Project Guidelines & Rules

## Git Workflow Rule
After each considerable change to the codebase (completing a sprint, implementing features, fixing bugs, or refactoring):
1. **Verify Integrity**: Run tests and build checks to ensure code is clean.
2. **Commit Changes**: Stage all relevant changes with a descriptive, structured commit message.
3. **Push to Git**: Push commits directly to remote (`git push origin main` or active branch).
